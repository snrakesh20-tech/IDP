# Data Quality Agent

This folder contains a browser prototype for the Data Quality Agent.

## Run it

1. Open a terminal in this folder.
2. Start a static HTTP server, for example with Python: `python -m http.server 8000`.
3. Open `http://localhost:8000` in a browser with internet access.

The page loads React, Babel, UI5 Web Components, and fonts from their CDN URLs. See [requirements.md](requirements.md) for the dependency list and current prototype limits.
